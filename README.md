# New Mass Gen

Локальна Windows-платформа для пакетної генерації зображень із таблиці через вебінтерфейс Gemini Create image. Oracle 0.21.6 керує окремими сесіями Chrome, а готові PNG/JPEG/WebP автоматично зберігаються у вибрану папку.

## Завантажити для Windows

- [New Mass Gen 1.5.0 — інсталятор](https://github.com/ye-shapovalov/new-mass-gen-images/releases/download/v1.5.0/New-Mass-Gen-Setup-1.5.0.exe) — рекомендований варіант.
- [New Mass Gen 1.5.0 — portable](https://github.com/ye-shapovalov/new-mass-gen-images/releases/download/v1.5.0/New-Mass-Gen-Portable-1.5.0.exe) — запуск без встановлення.

[Сторінка останнього релізу](https://github.com/ye-shapovalov/new-mass-gen-images/releases/latest) містить опис версії та всі доступні файли.

## Electron-версія для Windows

Electron-версія працює як звичайна програма Windows: локальний сервер запускається автоматично, інтерфейс відкривається в окремому вікні, а папку зображень можна обрати через системне вікно. Після закриття основного вікна програма залишається в системному треї, щоб активний пакет не переривався. Для повного завершення оберіть **«Вийти»** в меню значка New Mass Gen біля годинника.

Після встановлення або запуску portable-версії:

1. Відкрийте `New Mass Gen`.
2. Натисніть **«Обрати…»** в розділі «Папка зображень» і збережіть папку.
3. Налаштуйте стиль, акаунти Gemini та затримку між запитами.
4. Запустіть пакет. Вікно можна згорнути або закрити — робота продовжиться в треї.

Для запуску й складання з вихідного коду:

```powershell
npm ci
npm run desktop
npm run test:desktop
npm run dist:win
```

Готові файли з’являться в `dist/`: інсталятор `New-Mass-Gen-Setup-*.exe` і версія без встановлення `New-Mass-Gen-Portable-*.exe`.

## Вимоги

- Windows 10/11;
- Google Chrome;
- для готової Electron-версії Node.js не потрібен;
- для запуску вебверсії або складання з коду — Node.js 24 чи новіший;
- доступ до Gemini з функцією Create image;
- інтернет для першого встановлення залежностей і генерації.

## Запуск

1. Розпакуйте архів у звичайну локальну папку.
2. Двічі клацніть `Відкрити.cmd`.
3. Під час першого запуску дочекайтеся встановлення залежностей.
4. Якщо сторінка не відкрилася автоматично, запустіть `Відкрити.cmd` ще раз. Скрипт встановлює захищену локальну сесію без пароля або додаткових дій.

Альтернативний запуск із PowerShell:

```powershell
npm ci --ignore-scripts --no-audit --no-fund --cache .npm-cache
npm run open
```

## Перше налаштування

1. Вбудована таблиця містить лише три приклади: яблуко, грушу й апельсин. Натисніть **«Імпортувати CSV»**, щоб замінити її власною таблицею, та оберіть колонки назви й опису.
2. У розділі «Папка зображень» виберіть повний шлях для результатів.
3. Оберіть один із 10 візуальних шаблонів і одну з чотирьох палітр або введіть власний опис стилю. Натисніть «Застосувати шаблон» чи «Зберегти налаштування».
4. Залиште режим «Прихований Chrome генератора» для роботи у фоні.
5. Додайте потрібні акаунти Gemini.
6. Для кожного акаунта натисніть «Увійти», завершіть вхід у Chrome, закрийте вікно та натисніть «Перевірити сесію».
7. Увімкніть акаунти й задайте їх порядок кнопками ↑/↓.
8. Виберіть затримку між запитами. Початкове значення — 30 секунд.

## Генерація

1. Вкажіть номери як у друці Word: `1-3`, один номер `1` або вибірково `1,3,5,7-10`. Після збереження вибрані незавершені рядки стають у чергу, а невибрані — призупиняються. Якщо серед вибраних уже є готові зображення, програма запитає, чи потрібно їх перегенерувати; старі файли буде збережено в `_previous`.
2. Виберіть розмір пакета.
3. Натисніть «Генерувати пакет». Перед запуском програма автоматично перевірить папку, Oracle, Chrome і вхід першого ввімкненого акаунта. Жоден запит на зображення під час цієї перевірки не надсилається.

Платформа створює зображення послідовно, пропускає наявні файли й працює на першому ввімкненому акаунті. Після повідомлення про ліміт вона переходить до наступного акаунта. «Пауза» завершує поточне зображення і зупиняє чергу; «Зупинити зараз» перериває поточну спробу.

Основний стиль можна змінювати у будь-який момент, коли пакет зупинений. Збережений текст застосовується до нових генерацій і повторів, але не змінює вже готові зображення. Натисніть на рядок у списку, щоб переглянути та скопіювати повний сформований запит перед запуском.

Кнопка **«Керувати шаблонами»** відкриває бібліотеку з 10 готовими стилями та обкладинками. Кожен шаблон має чотири колірні палітри з видимими зразками. Будь-який шаблон можна редагувати, дублювати або видалити; вбудовані шаблони відновлюються окремою кнопкою. Для власного шаблону додайте назву, запит, обкладинку та чотири палітри. У готового рядка кнопка **«Використати як обкладинку шаблону»** копіює його зображення до вибраного шаблону. Власні обкладинки зберігаються лише у приватній локальній папці програми.

У картці рядка можна змінити назву, опис і сцену, призупинити лише цей рядок, повернути його в чергу або видалити з проєкту. Для готового рядка доступна перегенерація: попередній файл переноситься у підпапку `_previous`, а рядок знову стає в чергу. Ці дії доступні після зупинки або паузи пакета; видалення рядка не видаляє готовий файл.

Нові зображення автоматично записуються у вибрану папку. Кнопка «Зберегти всі готові картинки» копіює туди доступні готові файли, яких ще немає, без нових запитів до Gemini та без перезаписування наявних файлів.

## Якщо Gemini повертає текст замість картинки

Базова команда на генерацію в програмі вже сформульована англійською та прямо вимагає використати Create image. Якщо Gemini все одно відповідає як звичайний чат, програма показує причину в картці рядка, повторює запит один раз, вимикає цей акаунт і передає рядок наступному ввімкненому акаунту. Якщо іншого акаунта немає, пакет стає на паузу.

Для перевірки вручну надішліть проблемному акаунту простий запит `Create one square image of a red apple`. Якщо зображення не з’являється, генерація недоступна в поточній сесії або для цього акаунта — перевірте вхід чи використайте інший акаунт. Якщо простий тест працює, відредагуйте рядок: чітко опишіть один об’єкт або одну сцену, приберіть двозначні формулювання й, за можливості, напишіть назву, опис і стиль англійською.

## Безпека і локальні дані

- `input.csv` — три демонстраційні рядки, які замінюються імпортом власного CSV;
- `scenes.json` — демонстраційні уточнення сцен;
- `%LOCALAPPDATA%\NewMassGen\state.json` — локальний прогрес і налаштування;
- `%LOCALAPPDATA%\NewMassGen\account-profiles\` — приватні сесії входу;
- `%LOCALAPPDATA%\NewMassGen\template-images\` — власні обкладинки шаблонів;
- `%LOCALAPPDATA%\NewMassGen\runs\` — локальні запити та журнали;
- `output/images/` — початкова папка результатів.

Під час першого запуску після оновлення програма переносить стару `.data` до профілю Windows, зберігаючи входи та прогрес. Локальний API, журнали й зображення захищені автоматичною сесією, яку відкриває `Відкрити.cmd`.

Діагностичні знімки сторінки за замовчуванням вимкнені, оскільки можуть містити дані акаунта або текст Gemini. Їх можна тимчасово ввімкнути та видалити в блоці «Безпека та діагностика». Не публікуйте `%LOCALAPPDATA%\NewMassGen`, браузерні профілі, cookies, журнали або згенеровані файли без окремої перевірки.

Папки `.data`, `.npm-cache`, `node_modules` і `output` виключені з Git. `.data` залишається у списку виключень для сумісності зі старими версіями та тестовими середовищами.

Oracle 0.21.6 декларує залежності `fast-glob`, `micromatch` і `braces`, для яких npm наразі показує DoS-попередження без доступного виправлення. Студія не використовує Oracle CLI та не приймає glob-шаблони від користувача; ці три невикористані пакети також виключені з готової Electron-збірки. Перед оновленням Oracle його внутрішній браузерний API потрібно повторно перевірити.

## Перевірка

```powershell
npm test
npm run check:background
npm run check:release
```

GitHub Actions запускає ці перевірки та складає обидва Windows-файли після кожної зміни в `main`. Тег формату `v1.5.0` також створює GitHub Release. Перевірка релізу блокує випадково додані сесії, журнали, локальні шляхи, ключі та старі тематичні дані.

Збірка підтримує підпис Windows через секрети репозиторію `WINDOWS_CERTIFICATE` і `WINDOWS_CERTIFICATE_PASSWORD`. Без сертифіката програма працює, але Windows може показати попередження SmartScreen для нового невідомого видавця.

Вебінтерфейс Gemini, доступність моделей і ліміти можуть змінюватися. Після оновлення Chrome, Gemini або Oracle перевірте один тестовий пакет перед масовою генерацією.
