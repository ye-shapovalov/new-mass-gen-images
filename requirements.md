# Public template scope

New Mass Gen is a local Windows application for sequential image generation from CSV rows. The bundled `input.csv` contains only three replaceable examples: apple, pear, and orange. Users import their own table, select name and description columns, edit the shared visual style, and choose an output folder.

Each row becomes one square image. The queue supports editing a pending row, removing a row from the project, holding and resuming one row, retrying errors, and placing a finished row back into the queue for regeneration. Regeneration moves the previous image into `_previous` instead of deleting or overwriting it.

Oracle 0.21.6 drives Gemini Create image through persistent Chrome sessions. Accounts are ordered and enabled separately; generation uses the first enabled account until its quota is reached, then continues with the next one. Requests run sequentially with a configurable delay that defaults to 30 seconds.

The Electron application starts the local server automatically, stores progress and private browser sessions in the current Windows profile, protects local routes with an automatic session, and keeps a running batch alive in the system tray. The server listens only on localhost and rejects cross-site requests.

The public repository must never contain runtime state, Google sessions, diagnostic screenshots, generated images, credentials, tokens, or personal filesystem paths. `.data`, `output`, `dist`, browser profiles, and local caches stay excluded from Git.

Use Node 24, its standard library, the pinned Oracle dependency, and the existing plain HTML/CSS/JavaScript interface. Preserve files already generated by the user. Do not add parallel generation, hosted deployment, automatic quota reset, or another UI framework.
